Closed-loop manipulation, measured

A robot that checks its own work from camera pixels, and retries from the error it measured.

Natural language goes in. A local language model plans, a controller acts, and a separate camera-only verifier decides whether the block really ended up where it should. Every number here comes from a reproducible simulation benchmark, scored by ground truth the agent never sees.

What this is, and is not

  • Is: a controlled study of one question, how much does verifying from pixels and retrying from the measured error raise task success when execution is imperfect?
  • Is not: a learned manipulation policy. Skills are scripted waypoints, and the carry uses a disclosed kinematic grasp assist. Faults are injected on purpose, because a perfect scripted arm has nothing for a verifier to catch.

How it works

One loop per subtask. The ground-truth oracle sits outside it and is read only to score the result.

Perception

An overhead RGB-D camera with sensor noise. Colour segmentation plus depth gives block centres; a local VLM (Qwen3-VL via Ollama) is the alternative grounder. The arm is moved out of view before each look.

Verification and retry

The verifier measures where the block is relative to where it should be. A failed check yields an error vector. The corrected retry shifts the next release by that vector; the blind retry just repeats.
